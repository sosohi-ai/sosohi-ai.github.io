# Sohee Park

This repository hosts the personal academic website of **Sohee Park**, a Research Professor and AI Security Researcher at the **AI Safety Center, Soongsil University**.

My research focuses on the security, safety, and trustworthiness of artificial intelligence systems, with interests in:

- AI Model Security & Safety
- Privacy & Trustworthy AI
- Generative AI Security
- Adversarial Machine Learning

## Updating the Website

Edit the relevant JSON file in the [`data`](https://github.com/sosohi-ai/sosohi-ai.github.io/tree/main/data) folder and commit the change to `main`. The website will update automatically without editing the HTML files. See the [data editing guide](data/README.md) for details.
